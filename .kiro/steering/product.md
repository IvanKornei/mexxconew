# Product Overview

Cross-exchange arbitrage monitoring and trading system for cryptocurrency futures markets. Focuses on BTC/USDT pair between Binance Futures and MEXC Futures.

Core capabilities:
- Real-time price monitoring via WebSocket connections
- Spread calculation and arbitrage opportunity detection (>0.3% threshold after fees)
- Trading infrastructure ready for automated execution
- Live dashboard for monitoring prices and spreads

Target latency: <1ms for data processing to enable high-frequency arbitrage detection.
