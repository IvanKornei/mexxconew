# 🎮 Панель управления браузером - Полная документация

## 🎯 Обзор

Современная панель управления для полной эмуляции Chrome браузера с MEXC Futures. Все настройки, мониторинг и торговля в одном интерфейсе.

### Компоненты

- Primary: Синий градиент с hover эффектом

- Rounded corners (0.75rem)

- Hover эффект на интерактивных элементах

- Цветные точки с pulse анимацией
- Зеленый: Активен
- Желтый: Предупреждение
- Серый: Остановлен

**Формы:**
- Dark inputs с focus эффектом
- Checkboxes с custom стилями
- Selects с dropdown стрелками

## 🔧 API Endpoints

### GET /api/browser/status
Получить статус браузера.

**Response:**
```json
{
  "is_running": true,
  "is_logged_in": true,
  "current_url": "https://futures.mexc.com/exchange/BTC_USDT",
  "session_duration_seconds": 8100,
  "last_activity": "2026-03-07T15:30:00Z",
  "mode": "headless",
  "stealth_enabled": true,
  "human_behavior_enabled": true
}
```

### POST /api/browser/start
Запустить браузер.

**Request:**
```json
{
  "mode": "headless",
  "window_width": 1920,
  "window_height": 1080,
  "stealth_mode": true,
  "human_behavior": true,
  "typing_delay_min": 100,
  "typing_delay_max": 300,
  "click_delay_min": 200,
  "click_delay_max": 500,
  "auto_activity_enabled": true,
  "auto_activity_interval_minutes": 10,
  "screenshot_on_error": true,
  "timezone": "Europe/Moscow",
  "language": "ru-RU"
}
```

**Response:**
```json
{
  "success": true,
  "message": "Browser started successfully"
}
```

### POST /api/browser/stop
Остановить браузер.

**Response:**
```json
{
  "success": true,
  "message": "Browser stopped successfully"
}
```

### POST /api/browser/screenshot
Сделать скриншот.

**Response:**
```json
{
  "success": true,
  "path": "screenshots/mexc_20260307_153000.png"
}
```

### POST /api/browser/simulate-activity
Симулировать человеческую активность.

**Response:**
```json
{
  "success": true
}
```

### GET /api/browser/config
Получить конфигурацию.

### POST /api/browser/config
Сохранить конфигурацию.

### POST /api/browser/trade
Выполнить торговую операцию.

**Request (Market):**
```json
{
  "type": "market",
  "side": "BUY",
  "quantity": 0.001
}
```

**Request (Limit):**
```json
{
  "type": "limit",
  "side": "SELL",
  "price": 51000.0,
  "quantity": 0.001
}
```

**Request (Cancel):**
```json
{
  "type": "cancel",
  "order_id": "order_123456"
}
```

**Response:**
```json
{
  "success": true,
  "order_id": "order_123456"
}
```

### GET /api/browser/balance
Получить баланс.

**Response:**
```json
{
  "balance": 10523.45
}
```

### GET /api/browser/positions
Получить открытые позиции.

**Response:**
```json
[
  {
    "symbol": "BTC_USDT",
    "side": "LONG",
    "size": 0.01,
    "entry_price": 50000.0,
    "pnl": 125.50,
    "leverage": 200
  }
]
```

## 💡 Использование

### 1. Запуск системы

```bash
# Backend
cargo run --release

# Frontend
cd frontend
npm start
```

### 2. Открыть UI

```
http://localhost:4200/browser-control
```

### 3. Первый запуск

1. Перейдите на вкладку "Управление"
2. Нажмите "🚀 Запустить браузер"
3. Дождитесь статуса "✅ Активен"
4. Готово к торговле!

### 4. Настройка

1. Перейдите на вкладку "Настройки"
2. Настройте параметры под себя
3. Нажмите "💾 Сохранить настройки"
4. Перезапустите браузер для применения

### 5. Торговля

1. Перейдите на вкладку "Торговля"
2. Выберите тип ордера (Market/Limit)
3. Выберите направление (BUY/SELL)
4. Введите параметры
5. Нажмите "🚀 Разместить ордер"

### 6. Мониторинг

1. Перейдите на вкладку "Мониторинг"
2. Нажмите "🔄 Обновить" для актуальных данных
3. Следите за балансом и позициями

## 🎯 Best Practices

### Для HFT арбитража

```typescript
// Держите браузер всегда запущенным
await startBrowser();

// Быстрые ордера без задержек
config.human_behavior = false;
config.typing_delay_min = 0;
config.typing_delay_max = 0;
config.click_delay_min = 0;
config.click_delay_max = 0;

// Headless для скорости
config.mode = 'headless';
```

### Для безопасности

```typescript
// Максимальная эмуляция человека
config.human_behavior = true;
config.stealth_mode = true;
config.auto_activity_enabled = true;
config.auto_activity_interval_minutes = 10;

// Реалистичные задержки
config.typing_delay_min = 100;
config.typing_delay_max = 300;
config.click_delay_min = 200;
config.click_delay_max = 500;
```

### Для отладки

```typescript
// Visible режим чтобы видеть что происходит
config.mode = 'visible';

// Скриншоты при ошибках
config.screenshot_on_error = true;

// Можно вручную вмешаться в браузер
```
